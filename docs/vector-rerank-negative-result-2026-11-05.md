# 向量重排的负面结果：不接向量路（2026-11-05）

## 结论

**不接。** 用 bge-m3 余弦对字面粗筛结果重排，**比字面原顺序更差**。

## 数据（60 题子集，同一批题、同一库）

| 口径 | any@8 | 说明 |
|---|---|---|
| 字面粗筛（PRTS 真实检索） | **27/60 = 45.0%** | 与全量 479 题的 45.1% 一致 |
| top-50 内用 bge-m3 余弦重排 | **24/60 = 40.0%** | **−5.0pp** |
| 第一阶段理论上限（全量 any@50） | 62.0% | 重排本该往这里推，实际反向 |

耗 5.5 分钟（60 题 × 50 候选 × 512 字符截断，llama.cpp CPU 22.6ms/条）。

## 为什么会变差

PRTS 的字面检索不是单一 BM25，而是 **RRF 融合**（FTS5 trigram + LIKE 兜底 + 扩散激活，
权重 0.5 与 0.25）。它同时利用了：

- **词法精确匹配**：人名、数字、专有名词（LongMemEval 的 gold 大量依赖这类线索）
- **子串匹配**：trigram 对英文子串有效（`prefer` 命中 `preferred`）
- **关联证据**：扩散激活带来的同主题 turn

纯余弦只看语义相似度，把这些信号**全部替换掉**而不是补充。所以候选池里一旦混入
「语义相近但答案不对」的内容，重排就把它顶上来——与 2026-11-02 那次扩散激活的
教训同型（同权扩散把 any@8 从 32.8% 砸到 1.6%）。

## 与「题内 500 候选向量 90%」为什么不矛盾

之前 10 题子集实验里，向量在**题内 haystack（约 500 条）** 上 any@8 达到 9/10。
差别在候选集：

- 题内 500 条：全是该题会话，语义相关度本身就高，余弦足以区分。
- 全库 top-50：混入了**全库范围的语义近邻**，其中大量与 gold 主题相近但答案不对。

数量差 500 倍不是主要因素，**候选的纯净度**才是。

## 处置

1. `PRTS_EMBED` 保持默认关闭（现状即是），不追求默认开启。
2. `OpenAiCompatibleEmbedder`（`a19790d`）保留——它是可用且已测试的后端，将来若有
   适合向量的场景（如题内精排、画像匹配）可直接用，不必重写。
3. **不再投入**：全量 24.6 万 turn 向量化（原估 93 分钟 + 1 GB）没有对应收益，取消。
4. V1-17 基线保持 **45.1%（纯字面）**，向量不计入。

## 边界

- 60 题子集，不是全量；但 −5.0pp 的方向与既有两次「语义信号压过词法信号就变差」的
  实测同向，不认为扩到 479 题会反转。
- 只测了 bge-m3；换更强的 embedding 模型不改变「丢掉词法信号」这个机制。
- 只测了「重排 top-50」；top-10/20 内重排未测（那里余弦或许不亏，但收益上限也更低）。
