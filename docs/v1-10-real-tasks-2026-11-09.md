## 二、科研计算任务：谐振子基态能量

| 项 | 值 |
|---|---|
| 任务 | `task-5df74571-32b7-4737-9e5d-f55e0f485430` |
| 题目 | H = −½d²/dx² + x²/2（ħ=m=ω=1），理论 E₀ = 0.5，有限差分求最小特征值 |
| 产出 | `qho_ground_state.py`、`results.json`、`report.md`（3,392 B） |
| 账本证据 | 3 条，sha256 与磁盘三个文件**逐字符一致** |
| 验收 | 29 步（成功 29 / 失败 0），3 条证据 → `/accept` → `done` |

**模型结果**：三点差分外推 `0.50000000019`，五点差分外推 `0.49999999984`，两条路线互差 3.5e-10。
旁证三条（不依赖解析值）：virial 定理 ⟨T⟩=⟨V⟩=0.25（最细网格差 1.7e-11）、能级间距收敛到 1.0000000、变分高斯上界在 a=1/2 处正好 0.5。

**独立校验**（校验者实现，不复用模型代码）：

```
N      h          E0(三点差分, eigh_tridiagonal)   rel.err
201    0.100000   0.499687304320                    6.254e-04
401    0.050000   0.499921862787                    1.563e-04
801    0.025000   0.499980467987                    3.906e-05
1601   0.012500   0.499995117140                    9.766e-06
3201   0.006250   0.499998779296                    2.441e-06

独立 Richardson 外推（801/1601）→ 0.500000000191，与 0.5 偏差 1.907e-10
收敛比 e(801)/e(1601) = 4.000（h² 的理论值）
```

与模型的 `0.50000000019` 一致到 **1e-11**；实现路径不同（不同求解器、自写外推），构成独立校验。
