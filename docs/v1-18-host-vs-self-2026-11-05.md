# V1-18 宿主装配 vs 模型自管（首轮，2026-11-05）

**验收原文**（架构需求 §7）：「同一组记忆测试分别用两种方式运行，记录召回率、调用次数与费用，
用结果确认 §5.3 的待验证假设。」

**§5.3 的待验证假设**：宿主按规则确定性装配上下文优于「模型自管换页」（MemGPT 式）。
本轮给出第一份可复现数据，结论按样本量如实标注。

---

## 一、实验协议

| 项 | 值 |
|---|---|
| 数据集 | LongMemEval `s_cleaned`，分层抽样 **30 题**（6 个题型各 5 题） |
| 记忆库 | 复制 `C:/prts-benchmark/memory-s.sqlite` 到临时 dataRoot，`origin` 由 `benchmark` 改为 `live`（生产检索只读 live，设计稿 §6.4 的既有口径） |
| 模式 A「宿主装配」 | 默认接线：`memory-inject` 每轮自动注入检索结果（top-k）；`prts_memory_recall` 工具同时可用（生产形态） |
| 模式 B「模型自管」 | `PRTS_MEMORY_INJECT_BUDGET=0` 关闭自动注入；模型只能靠 `prts_memory_recall` 自行检索 |
| 被测模型 | `deepseek-chat`（`config/prts.yml` 默认） |
| 判分 | `scripts/eval-longmemeval.py`，`deepseek-reasoner`（同供应商不同模型，偏差已知且记录） |
| 指标 | QA 准确率、`prts_memory_recall` 调用次数/题、input/output token/题、秒/题 |

## 二、结果（n=30，0 invalid）

| 指标 | 宿主装配 | 模型自管 | 差异 |
|---|---|---|---|
| 准确率 | **46.7%**（14/30） | **43.3%**（13/30） | +1 题 |
| recall 调用/题 | 3.33 | 2.97 | +12% |
| input token/题 | 18,092 | 14,255 | **+27%** |
| output token/题 | 1,440 | 1,197 | +20% |
| 秒/题 | 16.5 | 15.7 | +5% |

分题型准确率（每类 5 题）：

| 题型 | 宿主 | 自管 |
|---|---|---|
| knowledge-update | **60%** | 40% |
| single-session-assistant | 80% | 80% |
| single-session-preference | 40% | 40% |
| single-session-user | 40% | 40% |
| temporal-reasoning | 40% | 40% |
| multi-session | 20% | 20% |

## 三、结论与边界

**能确定的**：
- 资源差异是真实的：宿主装配每题多 **27% input token**、多 12% 的 recall 调用、多 5% 时间。
  原因是自动注入把检索结果无条件放进上下文，而自管模式只在模型判断需要时检索。
- 在 `s_cleaned`（每题中位 491 turn）这个规模下，两种方式的准确率**没有可观察的差异**。

**不能确定的**：
- 准确率差 1 题（14 vs 13），30 题样本下与噪声不可区分——**不能据此说宿主装配更准，也不能说自管更准**。
  二项分布的 95% 区间约 ±18pp，判断准确率差异需要 100+ 题。
- 首轮 10 题时方向相反（宿主 50% / 自管 60%），进一步说明小样本结论会翻转。

**与 §5.3 假设的关系**：数据不支持「宿主装配必然优于模型自管」的强结论。宿主装配的
可辩护价值在于**确定性与可审计**（每轮装了什么可复现、可入清单），不在于准确率；
成本上它更贵。是否需要按题型或按会话规模切换策略，需要更大样本。

**局限**：
- 30 题、单一被测模型、分层取前 5 题/类的固定抽样。
- 判分器与被测模型同供应商（`judged_by=deepseek-reasoner`），偏差方向与幅度未知。
- 本实验的「模型自管」= 无自动注入 + 可用 `prts_memory_recall` 工具，**不是**完整的
  MemGPT 式上下文换页（PRTS 没有让模型管理上下文的换页机制）；结论不能外推到「完整自管」。


## 五、下一步（若要继续 V1-18）

1. 扩到 100+ 题：准确率才有统计意义；成本约 3-4 倍于本轮。
2. 按题型分层看差异：本轮 knowledge-update 的 60% vs 40% 是唯一非零差异（1 题），值得优先扩样。
3. 若目标只是「确认假设」，本轮数据已足够说明「宿主装配的准确率优势未被证实」；
   若要「决定生产策略」，还需要成本模型（V1-16 的单价）参与。
